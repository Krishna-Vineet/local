## Code Convention

Format: [PIECE]-[MEDIA]-[SLOTCOUNT]-[ORIENTATION]-[STRUCTURE]. Example: P1-46-T04-V-GRID2X2 = 1 piece, 4×6 media, 4 photo slots, vertical, 2×2 grid.

Orientation suffix: V = Vertical/Portrait, H = Horizontal/Landscape, S = Square. D = Digital. 360 = 360 booth family. Structure is the canonical arrangement.

- HSTACK — Horizontal stack

- GRID2X3 — 2 columns × 3 rows
- GRID4X2 — 4 columns × 2 rows
- GRID2X4 — 2 columns × 4 rows
- GRID3X3 — 3 columns × 3 rows

- 3HERO — Three dominant slots + one supporting slot
- HERO-R3 — Large hero left + 3 stacked/right slots
- HERO-L3 — Large hero right + 3 stacked/left slots
- HERO5 — One hero + 5 supporting slots
- HERO-L5 — Left hero + 5 supporting slots
- HERO-R5 — Right hero + 5 supporting slots
- HERO7 — One hero + 7 supporting slots
- TRIPTYCH — Three-panel composition
- CORNERS — Slots distributed around a central/branding area
- DIAGONAL — Diagonal visual arrangement
- CASCADE — Progressive staggered arrangement
- COLLAGE — Mixed-size editorial collage
- MOSAIC — Tiled/mixed mosaic arrangement
- FILM — Film-strip inspired arrangement
- POLAROID — Polaroid-card style arrangement
- SQUARE — Square-oriented photo slots
- MIX — Mixed slot sizes/orientations
- FULL — Single full-canvas slot

## Manual — How to Use This Catalog

Use the layout code as the stable structural identifier. Do not mix decorative theme names into the layout code.

Keep FORMAT, LAYOUT, PHOTO SLOT, MASK/SHAPE, DESIGN, TEXT, and DECORATION as separate layers.

Use top-left origin: X increases left→right and Y increases top→bottom.

Prefer normalized coordinates (0–1) in the layout engine, then calculate pixels from the active canvas size.

Treat the listed dimensions as reference canvas sizes. The same structural layout can be rendered at another supported size.

Keep photo fitting separate from slot geometry. Recommended modes: COVER, CONTAIN, FIT, and CROP.

Decorative backgrounds, borders, flowers, logos, names, dates, and AI artwork must not define the photo-slot geometry.

When creating a new layout, choose an existing family and structure first; create a new code only when the structural arrangement is genuinely different.

Do not assume T04 means one exact arrangement. T04 only describes four slots; the final structure is identified by the suffix such as GRID2X2, HERO3, COLLAGE, etc.

Before publishing a layout, validate that every slot stays inside the safe area and that branding/text does not overlap the photo masks unless intentionally designed.
