We have one whole project with common packages, libraries and types.
It has two seperate folder in src, ui and electron.
ui contains all the react - frontend code and electron contains all the  code that will make an app, run IPC connectors, call backend api using node http requests, camera/ printer interface code, etc.

the electron and related stuff are dev dependencies, as the final output of this code will be an app after compilation.

Step 1: Frontend is in React TS, we need simple html css js, so first we will build frontend using npm run build:react and it will be stores in dist-react.

Step 2: Electron is also in TS, it is seperate process as of now, so we will transpile it to convert into JS using  npm run transpile:electron, it will be stored in dist-electron.

Step 3: Now we have two folders dist-react and dist-electron. and we need to combine them to create an app. we can use electron-builder to build the app using commands like 
- `npm run dist:mac` (for mac)
- `npm run dist:win` (for windows)
- `npm run dist:linux` (for linux)



To run electron builder and get the output app, we first need to run `npm run build:react` and `npm run transpile:electron`, only then we can run electron-builder, however i have combine all those scripts under `npm run dist:win`, `npm run dist:mac`, and `npm run dist:linux`.

When, in development, if you want to test things, the react will just run on port 8888 using `npm run dev:react`. But electron still need to transpile first to get new changes using `npm run transpile:electron` and then you can run it, however i have combined both scripts under `npm run dev:electron`, which will in development, load the url http://localhost:8888. So, the frontend must be running on port 8888 using command `npm run dev:react` before running `npm run dev:electron`.

However in production, both will get built, and electron will load the index.html from dist-react.

I am using a package 'npm-run-all' to run frontend and backend commands simultaneously in parallel using command `npm run dev`.



Building: converting complex framework code (react) into simple html, css, js files. We have React+TS, so first it also get transpiled (tsc -b) into react+js and then bundled and minified, etc (vite build) into final html, css, js files, and it happens in dist-react folder using only one command `npm run build:react`.

Transpiling: converting TS into JS. we will be transpiling both react and electron after any major code update to check fot type safety.

Bundling: taking all the final html, css, js, frontend, backend files and other necessary cpnfiguration files and wrapping them into an app using electron-builder to get the final app.
